# Sphinx Installer
It offers to install the Python-based Sphinx documentation generator without having Python globally installed.
The option of using PyInstaller was explored but the generator became very slow.

## Dependencies
- [Inno Setup](https://jrsoftware.org/isinfo.php) 6.3.3
- [DwinsHs](https://www.han-soft.com/dwinshs.php) 1.3.1.157
- [Sphinx](https://pypi.org/project/Sphinx/) 4.1.2
- [Python](https://www.python.org/) 3.11.9
- [pip](https://pypi.org/project/pip/)

## Additional Sphinx extensions
- [sphinx-rtd-theme](https://pypi.org/project/sphinx-rtd-theme/) 2.0.0
- [readthedocs-sphinx-search](https://pypi.org/project/readthedocs-sphinx-search/) 0.3.2
- [sphinxcontrib-imagesvg](https://pypi.org/project/sphinxcontrib-imagesvg/) 0.1.0
- [sphinx-press-theme](https://pypi.org/project/sphinx-press-theme/) 0.9.1
- [sphinx-last-updated-by-git](https://pypi.org/project/sphinx-last-updated-by-git/) 0.3.7
